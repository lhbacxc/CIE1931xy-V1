# 箭头标注设计

## 目标与范围

在 `codex/arrows` 分支实现已选定的推荐方案：手动选择两个已绘制点，创建由起点指向终点的直线或弯曲箭头。箭头用于说明变化方向，不代表经过中间测量点的真实轨迹。

## 交互

- 右侧绘图操作栏增加「添加箭头」「管理箭头」，视图菜单提供同名入口。
- 起点、终点列表统一包含可见光谱的计算点和独立坐标点；显示来源、序号、名称及当前图型坐标，以区分同名数据。
- 新箭头默认白色、2.5 线宽、黑色细描边；直线为默认样式。
- 弯曲模式提供弯曲程度 0–100% 与向左/向右弯（沿起点到终点方向观察）。颜色、线宽 1–12、描边开关和描边颜色可编辑。
- 编辑窗口有即时箭头示意预览；应用才修改模型，取消保留原值。
- 管理窗口列出全部箭头，可添加、编辑、删除；隐藏端点对应的箭头仍列出，并标记暂时隐藏。
- 少于两个可用点时禁用添加；拒绝相同端点及重合坐标。点距离过近时按画布空间缩小箭头，空间不足则不画，避免覆盖点。

## 模型与生命周期

- `ArrowEndpoint` 持有 CieCurve 或 CiePoint 的模型引用，不通过名称或表格行号关联。重命名、表格刷新和 xy/u'v' 切换不改变关联。
- `CieArrow` 保存端点、类型、颜色、线宽、曲率、弯曲方向及描边设置。
- MainForm 持有独立箭头列表；隐藏光谱时暂不绘制相关箭头，恢复后重新显示。删除端点时清理关联箭头，清空数据时同时清空箭头。
- 箭头与导入数据同属当前会话数据，不写入软件偏好 JSON；CSV/TXT 的计算字段不增加箭头内容。

## 绘制与导出

- ArrowGeometry 共用曲线与箭头三角形几何。端部沿曲线在点标记外留间隙，箭头头部按终点切线定向。
- IPlotCanvas 增加三次贝塞尔与局部裁剪；GDI 使用 DrawBezier，SVG 使用 path C，避免折线或 SVG 二次平滑改变形状。
- 箭头在数据标记之前绘制，限制在绘图区内，点标记和文字保持在上层。
- 预览与 PNG/TIFF/SVG 接收同一箭头列表、使用同一渲染器；兼容原有无箭头调用，经典界面不接入。

## 验证

- 源码构建、两套经典 oracle 与原有数值/解析自检。
- 箭头几何：方向、直线/曲率零、左右弯、标记间隙、近点与重合点、终点切线及裁剪。
- 图片导出：xy/u'v'、颜色/描边、PNG/TIFF/SVG；SVG 保持纯矢量，原有无箭头输出保持一致。
- 实际 WinForms 交互：添加、编辑、取消、管理删除、端点重命名、光谱隐藏/恢复、删除端点与清空数据。
- 本机 DPI 与模拟 100%–200% 的主界面/箭头窗口布局，以及缩放后的示意预览。

当前版本保持 2.0.0；本分支完成后可供审核，不自动合并或替换已发布的 v2.0.0 Release。
