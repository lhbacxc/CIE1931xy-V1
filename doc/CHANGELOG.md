## 6. 第六轮修订：表格、输入、导出与绘图细节（v2.0.0）

| 类别 | 现在的行为 |
| --- | --- |
| 启动 | 默认空白图，不自动载入示例（示例按钮已移除） |
| 页签 | 三个：光谱曲线 / 三刺激值 / 坐标点（“色度坐标”页签已合并删除） |
| 光谱曲线表 | 只显示 **名称、形状、颜色、描边** 四列；形状默认圆形，颜色默认黑（多曲线按高对比色循环），描边默认黑 |
| 选择与删除 | 表格支持 Ctrl / Shift 多选；选中项在图上有蓝色高亮圈（**导出时不含高亮**）；按 Delete 删除选中行 |
| 名称来源 | 导入单个文件用**文件名**作名称；一个文件里多条曲线时用各自的**标签**作名称 |
| 名称批量修改 | 菜单 文件 → **批量修改名称…（Ctrl+H）**：Word 式查找/替换，可限定范围（曲线/坐标点/两者）、区分大小写；查找留空 = 统一改名；替换文本里的 `{n}` 会变成序号 |
| 输入坐标 / 粘贴 | 顶部“输入坐标”按钮打开多行输入框（不再是“导入坐标”）；右侧新增“粘贴”按钮（Ctrl+Shift+V 可粘贴光谱或坐标） |
| 轴范围 | 固定 `x: 0–0.8`、`y: 0–0.9`，与位图底图一致，不再提供手动设置 |
| 1976 u'v' | 只能选矢量背景（位图底图没有 u'v' 版本） |
| 数据标签 | 勾选“数据标签”后显示每条数据/每个点的名称 |
| 网格 | 与位图一致：0.05 一格细线 + 0.10 一格主线 |
| 波长标注 | 每个波长数字旁有一小段法向刻度线 |
| 黑体线 | 黑色、加粗；刻度加长，温度数字沿刻度末端**奇偶交替**上下排布，高温端标 ∞ |
| 闭合线 | 位图上那条 `x + y = 1` 的灰线现在矢量图也画（可在 `DiagramStyle.ShowClosingLine` 关掉） |
| SVG 导出 | 曲线/轨迹统一加 `stroke-linecap="round"` 消除接缝；真彩背景改为矢量色块（不再内嵌 PNG），全文不含 `<image>` |
| 导出文件名 | 记住上次的文件名，下次导出自动填入 |
| 经典界面 | 从“视图 → 打开经典界面”打开时按 DPI 缩放（不再整体偏小），按钮与标签文字自适应 |

## 8. 第八轮修订：矢量导出平滑、点击选中与布局（v2.0.0）

|---|------|----------|

### 第八轮补丁（同日）

- **导入数据统一红色**：`NextColor()` 直接返回红 `#D62728`，不再五颜六色（要区分时选中后用「颜色」按钮修改）。
- **矢量图外框加粗**：坐标框线宽 1.4 → 2.6 px（按 DPI 缩放）。
- **数据点和光谱曲线描边可见**：描边宽度 1.4 → 1.8 px，半径外扩 0.6 px；**曲线标记以前完全没画描边**（只有坐标点画），这次一并补上，两种数据的黑边都清晰（SVG 里是 `<ellipse ... stroke="#000000" stroke-width="1.8"/>`）。

> 生成的 SVG 里不再内嵌位图：真彩背景由矢量色块 + 裁剪路径组成，曲线用二次贝塞尔 `<path>` 绘制（`stroke-linecap="round"`），整张图都是矢量。
