# CIE1931xy 2.1.0

新增点列旁的箭头方向标注，并将功能合并到 main。Windows x64 轻量单文件版与自带运行时的便携版均包含箭头功能。

## 下载选择

| 文件 | 使用方式 |
| --- | --- |
| `CIE1931xy-v2.1.0-win-x64.exe` | 轻量单文件，需要 .NET 8 Desktop Runtime x64 |
| `CIE1931xy-v2.1.0-win-x64-portable.zip` | 推荐普通用户下载；解压后打开 `./CIE1931xy.exe`，无需额外安装 .NET |
| `SHA256SUMS.txt` | 两个软件下载文件的 SHA256 校验值 |

轻量版所需运行时可从 [Microsoft .NET 8 下载页](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) 的「.NET Desktop Runtime → Windows → x64」下载；普通 .NET Runtime 不包含 WinForms 支持，运行软件无需 SDK。

便携版使用压缩的自包含单文件 exe，包含 .NETCore / WindowsDesktop 8.0.34。首次启动会自动解包组件到用户临时目录，请完整解压到可写目录运行。更新时保留 `./CIE1931xy.settings.json`，替换程序即可；便携包内保留 .NET 许可和第三方声明。

## 新增箭头功能

1. 绘制数据点后，点击右上「添加箭头」，选择方向参考的起点和终点，支持光谱计算点和独立色坐标点。
2. 箭头初始放在点列旁边，方向为起点 → 终点；用鼠标按住箭身或箭头头部拖动，整体平移并保持参考方向。
3. 默认白色，可调整颜色、线宽、细描边；支持直线和弯曲箭头，弯曲程度及左右朝向可编辑。
4. 「管理箭头」可添加、编辑、删除多条箭头；编辑保留已拖动的位置，取消不修改原设置。
5. xy/u'v' 切换与 PNG/TIFF/SVG 导出同步使用当前箭头位置，预览中的选中高亮不进入导出。

参考点改名时保留绑定；隐藏光谱时相关箭头暂时隐藏，恢复后重新显示。删除参考端点会一并删除相关箭头，清空数据同时清空箭头。箭头和导入数据仅保留在当前会话，不写入偏好配置或 CSV/TXT；原始渐变色箭头设想尚未实现。
