# CIE1931xy 2.0.0

首次公开发布 CIE1931xy 重建版，提供 Windows x64 轻量版与自带 .NET 8 桌面运行时的便携版。

## 下载选择

| 文件 | 使用方式 |
| --- | --- |
| `CIE1931xy-v2.0.0-win-x64.exe` | 轻量单文件，约 1 MB；需要 .NET 8 Desktop Runtime x64 |
| `CIE1931xy-v2.0.0-win-x64-portable.zip` | 推荐普通用户下载；解压后双击 `./CIE1931xy.exe`，无需额外安装 .NET |
| `SHA256SUMS.txt` | 两个软件下载文件的 SHA256 校验值 |

轻量版需要的运行时可从 [Microsoft .NET 8 下载页](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) 的「.NET Desktop Runtime → Windows → x64」下载；普通 .NET Runtime 不包含 WinForms 支持，运行软件无需 SDK。

便携版内置 .NETCore / WindowsDesktop 8.0.34，exe 启用了单文件内部压缩。首次运行会自动解包组件到用户临时目录；请将下载包解压到可写目录，方便保存程序旁的设置文件。包内保留 .NET 的许可和第三方声明。

## 主要功能

- 导入多列光谱或独立色坐标，支持手动输入、Excel 粘贴与文件拖放。
- 计算 XYZ、xy、u'v'、峰值及 CCT，绘制 CIE 1931 xy / CIE 1976 u'v' 色度图。
- PNG、TIFF 和纯矢量 SVG 图片导出，以及 CSV / TXT 结果导出。
- 修改点标记、颜色、描边和名称，批量改名；光谱支持隐藏/显示与快捷键。
- 网格、黑体轨迹、参考线、图例及标签开关，黑白画布背景切换。
- 中英文字体与六类文字大小设置，坐标轴标题与间距调整。
- 软件偏好保存到 `./CIE1931xy.settings.json`，下次启动恢复；更新时保留该文件。
- 保留经典 1.6.0.2 界面及计算语义，可使用 `--classic` 打开。

## 验证与边界

- Release 源码构建通过：0 警告、0 错误；两套经典 oracle 各 9/9，新版数值、解析与 PNG/SVG/CSV/TXT 自检通过。
- 两种实际发布 exe 均通过自检；隔离系统 .NET 路径时，轻量版正确提示缺少运行时，便携版自检与实际新版窗口启动通过。
- 本轮未新增完整界面自动化、跨显示器 DPI 或 TIFF 专项验收；此前功能验证范围见仓库开发指南。
- 光谱与坐标数据只保存在内存，尚无工程文件保存功能；仅软件偏好会自动保存。
- 当前 Δuv 为非负距离，不是带符号的标准 Duv；计算口径与经典兼容边界见 README 和架构说明。
