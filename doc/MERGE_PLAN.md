## 5. 明确不做的事

- 不改动外部 CIEdraw 项目的任何文件（原计划只在 C 阶段读取它的数据表作为参考）。
- 不引入跨平台 UI 框架（继续 WinForms，理由：现有逆向成果与像素级验证都在 GDI+ 上）。
- 不做"逐像素复刻 CIEdraw 的 matplotlib 外观"——图由我们自己的渲染器画，风格接近但不追求像素一致。
- **不做 PDF 导出**（你的明确要求）。
